# Deep_Learning_IoT
The objective is to develop novel Deep Learning architectures for identification of network traffic with malicious signatures. 
The High-Level Workflow :
1.Traffic Ingestion;
2.Signal Construction (e.g., Flow Timing );
3.DSP Filter Bank ( e.g., Low-Pass / High-Pass / Band-Pass / Band-Stop / Wavelets);
4.Feature Extraction (e.g., time & frequency );
5.Deep Learning Stack (e.g., Autoencoder (AE) / Convolutional Neural Network (CNN) / Long Short-Term Memory Network(LSTM) / Semi-Supervised Support Vector Machine (S3VM));
6.Threat Classification;
7.Alerting;
8.Feedback.
